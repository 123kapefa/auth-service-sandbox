# Этап 10.9. Кабинет: способы входа и смена номера

**Статус:** ✅ готово · **Задача:** [#137](https://github.com/123kapefa/auth-service-sandbox/issues/137) (этап 10 — [#128](https://github.com/123kapefa/auth-service-sandbox/issues/128))

Экраны кабинета по макетам этапа 10 (01–04, 08, 14): человек сам выключает пароль и коды
([10.3](10-sign-in-methods.md)) и сам меняет номер ([10.5](10-phone-change.md)).

## Безопасность → «Способы входа»

| Строка | Метка | Подпись | Кнопки |
|---|---|---|---|
| Пароль | включён / выключен / не задан | «Задан…»; выключен — «с 05.10.2026, 18:40 · «Забыли пароль» тоже не работает» (дата — из истории) | «Сменить» (или «Задать»), «Выключить» / «Включить» |
| Код на телефон | включён / выключен / нет номера | «+7 912 345-67-89 · звонком, если не дошёл — SMS» | «Выключить» / «Включить» |
| Код на почту | включён / выключен / нет почты | «на anna@mail.ru»; нет почты — «Добавьте почту в профиле» | «Выключить» / «Включить» |
| Ключ доступа | «2 ключа» / нет, «надёжный» | названия ключей — «список ниже» | «Добавить» |
| Яндекс ID, Госуслуги | привязан | — | — |

- **Выключить** — окно (экран 03): что перестанет работать, «Останутся:» (ключи, другие включённые способы, внешний
  вход), галочка «Выйти на других устройствах (N)» — по умолчанию стоит. «Включить» — без окна.
- **Нельзя выключить** — кнопка неактивна, почему — по `disableBlocker` из API: нет ключа доступа и приложения —
  объяснение «Сначала добавьте надёжный способ» с кнопками «Добавить ключ доступа» и «Подключить приложение» (экран 04);
  последний способ и «сначала коды восстановления» — в подписи строки.
- **Вход был давно** — сервис отвечает `auth.reauthentication_required`, кабинет показывает уведомление с «Войти
  заново»; после входа человек нажимает ещё раз.
- **Выключенное в проекте** (10.7) не показывается: строка способа, ключи доступа (и раздел «Ключи доступа»), Яндекс
  ID, Госуслуги. Сервис отдаёт это полем `projectDisabled` в `GET /me/sign-in-methods`; переходный период —
  ещё не выключен. Плагин способов проекта недоступен — список пустой, кабинет показывает всё, как раньше.

Ниже — прежние разделы: 2FA, коды восстановления, список ключей доступа.

## Профиль → «Телефон»

Номер в виде `+7 912 345-67-89` и с какого числа он (`phoneChangedAt` в `GET /me/profile`, не меняли — дата
создания аккаунта), кнопка «Сменить номер» → страница Keycloak (`action=update-phone`, 10.5); после возврата —
уведомление «Номер изменён». Вход по телефону выключен в проекте — кнопки нет.

## Телефон (экран 08)

На узком экране меню свёрнуто в шапку с кнопкой «☰» (общий каркас — и в админке): раскрывается над содержимым,
выбрали раздел — сворачивается. Строки способов переносят кнопки под подпись.

## Галочки

Галочки кабинета и админки — как в наборе компонентов (Kit) и на страницах входа: квадрат с рамкой, включённая залита
(`input[type=checkbox]` в `frontend/src/app/styles.css`). Своих классов на галочки не вешать.

## Решения по умолчанию

- «Отвязать» у Яндекс ID и Госуслуг (на макете есть) — не сделано: у сервиса нет такого действия, нужны правила
  «последний способ», письмо и журнал. Строка только показывает, что вход привязан.
- «Сменить» пароль — в строке «Пароль», отдельного раздела «Пароль» больше нет.
- Включить способ обратно можно без окна: это не ослабляет вход.
