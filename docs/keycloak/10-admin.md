# Этап 10.10. Админка: вход и коды, способы входа человека

**Статус:** ✅ готово · **Задача:** [#138](https://github.com/123kapefa/auth-service-sandbox/issues/138) (этап 10 — [#128](https://github.com/123kapefa/auth-service-sandbox/issues/128))

Экраны админки по макетам этапа 10 (07, 15, 22) поверх API [10.7](10-code-settings.md) и [10.3](10-sign-in-methods.md).
Сервис не менялся — только интерфейс.

## «Вход и коды» (право `sign-in.manage`, пункт меню 06)

| Блок | Что видно и что можно |
|---|---|
| Способы входа в проекте (экран 22) | телефон, почта, пароль, ключ доступа, Яндекс ID, Госуслуги: метка «включён» / «выключен» / «до 06.11.2026», подпись, «Выключить» / «Включить»; 2FA — «по желанию» или «обязательна» |
| Сегодня (экран 15) | звонки, SMS (≈ ₽ и доля от кодов), письма, доля введённых кодов (ниже 60 % — плитка в штриховке), бюджет дня полосой; кончился — «SMS выключены до полуночи». Обновляется раз в минуту |
| Каналы | порядок «Ключ доступа → Почта → Звонок → SMS» (выключенное — зачёркнуто), звонки и SMS, страны (`+7, +375`), дневной бюджет в рублях (0 — без бюджета), «Сохранить» |
| Защита от накрутки | на номер в час и в сутки, с одного IP, на диапазон номеров, капча после N отправок |

- **Выключить способ** — окно: сколько людей входят **только** этим способом (`…/affected`, считается при открытии
  окна), «Сразу» или «С переходным периодом до» (телефон, почта, пароль; по умолчанию — через 30 дней, не дальше
  года), каким станет поле входа. Последний способ регистрации выключить нельзя — окно объясняет. Способ в переходном
  периоде — «Изменить срок» (то же окно) и «Включить».
- **Включить** — без окна. Яндекс ID и Госуслуги без ключей проекта не включаются (подпись «нужны ключи проекта»).
- **2FA обязательной / по желанию** — с подтверждением.
- Каналы и защита — одна форма: сохраняется целиком, проверки — как у сервиса (хотя бы звонки или SMS, до 20 стран,
  бюджет до 10 млн ₽, лимиты в пределах, в сутки не меньше, чем в час).
- Каждый блок грузится сам: нет плагина или прав у одного — остальные работают.

## Карточка пользователя (экран 07)

- **Способы входа** (право `users.view`): пароль, код на телефон, код на почту — метка и кто и когда выключил
  («человеком, 05.10.2026, 18:40»); ключи доступа, 2FA, коды восстановления — есть или нет; привязанный внешний вход.
  Админ ничего не выключает за человека.
- **Вернуть способы по умолчанию** (право `users.credentials.manage`) — панель в штриховке с подтверждением: пароль и
  коды снова работают, ключи остаются, человеку — письмо. Себе и когда всё включено — кнопка неактивна с причиной.
  Вход был давно — уведомление «Войти заново».
- **Пароль и 2FA** — теперь сразу под способами входа. Человек выключил пароль — «Отправить ссылку для смены пароля»
  неактивна: «Ссылка не отправляется: вход по паролю у человека выключен.»

## Решения по умолчанию

- Сколько людей входят способом — только в окне выключения, не в строках: сервис считает перебором всех людей, на
  каждый способ при открытии страницы было бы шесть медленных запросов.
- Ключи доступа и коды восстановления в карточке — «есть / нет»: API не отдаёт админу названия ключей и счёт кодов.
- Выбор «Сразу / С переходным периодом» — квадратом, как галочка (так на макете): общий стиль `input[type=radio]`
  в `styles.css`.
- Если в настройках сервера лимит больше, чем разрешено менять админу (на стенде — 1000 в час), форма подсветит поле:
  сохранить можно, только уменьшив его.
- Письмо админам при 80 % и 100 % бюджета — по-прежнему позже (в подписи бюджета — как задумано).

## Проверка

```bash
cd frontend && npm run lint && npm run type-check && npm test   # 108 тестов, из них новые — коды, способы проекта, сброс, карточка, меню
```

На стенде (образ сервиса с новой админкой): админ видит «Вход и коды», выключает вход по телефону с переходным
периодом (51 человек входит только так) и включает обратно; форма кодов не пропускает «без звонков и SMS»; человек
выключил пароль в кабинете — в карточке «выключен человеком, дата», ссылка на смену пароля неактивна, «Вернуть
способы по умолчанию» включает пароль.
