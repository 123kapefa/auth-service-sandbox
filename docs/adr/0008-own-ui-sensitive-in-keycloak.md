# 0008. Своя админка и кабинет; пароли и секреты — только на страницах Keycloak

**Статус:** Предложено · **Дата:** 2026-10-05 · **Этапы:** 4б, 4в, 6б

## Контекст

Админка Keycloak — про весь сервер: её нельзя дать админу проекта или приложения. Кабинет Keycloak — свой стиль и
своя логика. Нужны интерфейсы в стиле проекта, но без того, чтобы наш код видел пароли и секреты.

## Решение

- **Админка** (`/admin`) и **кабинет** (`/account`) — свои, на React, в образе сервиса входа. Ходят только в API
  сервиса; Admin API Keycloak — от служебной учётки с узкими правами.
- **Чувствительное** — пароль, новая почта, 2FA, ключ доступа — вводится только на страницах Keycloak (наша тема):
  кабинет просит действие (`kc_action`) и показывает итог.
- **Страницы входа и письма** — тема Keycloakify; название, логотип и цвета проекта и приложения — из админки, без
  пересборки.

## Последствия

- Сервис входа не видит паролей и секретов 2FA.
- Без JavaScript не войти — страницы рисует React (боевой вход работает и без него).
- Обновление Keycloak может потребовать обновить Keycloakify.
- Кабинет Keycloak (`account-console`) пока включён — им можно пользоваться в обход своего; закрыть — решить отдельно.

## Что отвергли

- **Свои страницы ввода пароля и 2FA** через Admin API — наш код видит секреты, больше кода и риска.
- **Админка Keycloak для админов проектов** — даёт доступ ко всему серверу.
