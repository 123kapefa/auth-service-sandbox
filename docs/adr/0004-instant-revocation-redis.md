# 0004. Мгновенный отзыв токенов через Redis

**Статус:** Предложено · **Дата:** 2026-10-05 · **Этапы:** 4, 4а

## Контекст

Сервисы проверяют JWT по подписи, без Keycloak. Поэтому после блокировки, выхода или смены ролей access-токен жил
до конца срока — до 15 минут. Боевой сервис живёт так же.

## Решение

Сервис входа ставит отметку в Redis: сессия (`sid`), пользователь (`sub`, время), доступ к приложению, версия
доступа. Пакет `Platform.Authentication.Redis` у каждого сервиса проверяет отметку после подписи (`OnTokenValidated`):
отозван — 401, доступ изменился — 401 `access_changed` (клиент делает refresh). Отметки живут 16 минут — дольше
токена. Сессии, завершённые в самом Keycloak, приходят через back-channel logout.

## Последствия

- Блокировка, «выйти везде», смена ролей — действуют сразу (на других экземплярах — за время кэша, до 2 с).
- Redis — обязательная зависимость каждого сервиса проекта; без него отзыв не работает (токены живут ≤ 15 минут,
  предупреждение в лог).
- После пересоздания стенда отметки прошлого надо чистить (`FLUSHALL`).

## Что отвергли

- **Короткие токены (1–2 минуты)** — refresh в разы чаще, нагрузка на Keycloak, отзыв всё равно не мгновенный.
- **Introspection на каждый запрос** — каждый запрос любого сервиса идёт в Keycloak.
