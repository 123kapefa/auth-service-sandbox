# Планы, цена и открытые вопросы

Что осталось сделать, чего это стоит и когда пересматривать решение. Обновляйте при каждом закрытом пункте.
Решения, на которых это основано, — в [ADR](adr/README.md), устройство — в [architecture.md](architecture.md).

## Что не проверено

- Существующий проект (тестовая копия education-platform): проверены два сервиса из десяти (`tag`, `education`) и редирект
  фронтенда на страницы входа, не весь круг входа в браузере с кабинетом и не остальные восемь сервисов. Перенос
  пользователей реального проекта — отдельно ([migrating-users.md](../migrating-users.md)). Переезд обошёлся без
  переписывания авторизации сервисов: решение о Keycloak подтверждено ([pitfalls.md](pitfalls.md#существующий-проект-education-platform)).
- Нагрузка: вход, refresh, проверка отзыва.
- Кластер Keycloak под нагрузкой, настоящий провайдер звонков и SMS, настоящие ключи Яндекса и ЕСИА.
- Публикация релиза по тегу: первым будет `v0.1.0`; видимость образов и пакетов (открыть или читать с токеном).
- Infisical в Kubernetes и Ingress с https — проверены только `helm lint`, в kind их нет.

## До боя

Оценка в днях одного разработчика, знающего код.

| Что | Оценка |
|---|---|
| Вход по коду до прод-качества: провайдер звонков и SMS (`PhoneProvider`), ключи Яндекс SmartCaptcha (без ключа после порога код не уходит), тесты плагина в CI | ~1 неделя |
| Резервные копии Postgres по расписанию с проверкой восстановления; мониторинг, метрики, оповещения | 3–4 дня |
| Перенос существующего проекта и правки по журналу трений | ~1 неделя |
| Хвосты: ответы 401/403 в `Envelope`; `available_roles` строкой (если нужна совместимость со старыми потребителями) | 2–3 дня |
| Нагрузочный прогон | 2–3 дня |
| **Итого** | **~3–4 недели** |

Постоянная цена: обновления Keycloak (пересборка плагина и темы, прогон проверок), человек, готовый поддерживать Java
внутри Keycloak, эксплуатация Keycloak (своя БД, кластер, обновления схемы, журнал 30 дней), стоимость звонков и SMS
и слежение за долей введённых кодов.

Размер своего кода (конец этапа 11, без тестов и миграций, порядок величин): плагин Keycloak ~7 500 строк Java, тема ~3 400,
сервис входа ~12 900, общие пакеты ~1 700, админка и кабинет ~8 600, перенос ~550, скрипты ~6 600. Проверок на стенде
~900, тестов ~830 (.NET ~530, плагин ~140, интерфейсы ~170). Без этого кода Keycloak — только его консоль: Admin API
нельзя отдавать браузеру, а режимы, админ приложения и step-up в Keycloak не заложены.

## Открытые вопросы и хвосты

| Что | Состояние | Решение / идея |
|---|---|---|
| Ответы 401/403 без `Envelope` | в `Envelope` только 401 `access_changed`, остальное — стандартные ASP.NET | единый формат ошибок |
| `available_roles` | в Keycloak массив, в старом сервисе — строка | при переезде менять потребителей или сделать маппер в строку |
| Письмо «почта изменена» на старый адрес | Keycloak не шлёт | решить, нужно ли |
| Вход без JavaScript | невозможен | принято как цена React-страниц |
| E2E-тесты в браузере | нет | при необходимости добавить |
| Счётчики лимитов кодов | не атомарны | проверить под нагрузкой при кластере |
| Подсчёт «сколько людей входят только так» | перебор всех людей проекта | счётчик или фоновый подсчёт на большом проекте |
| Способы входа для одного приложения | нет: вход общий на проект (SSO) | step-up для приложения |
| Привязка внешнего входа только паролем | кто входит только по коду, привязать не может | подтверждение кодом из SMS вместо `platform-link-password` |
| Обновление данных внешнего входа | `syncMode: IMPORT`, не обновляются | включить синхронизацию |
| Подпись ответов ЕСИА | не проверяется (токен напрямую от ЕСИА по TLS) | проверка ГОСТ-подписи сервисом подписи |
| Отвязать внешний вход в админке сервиса | только в консоли Keycloak, в обход правил | своё действие с правилом «последний способ», письмом и журналом |
| Смена номера за человека | только в консоли Keycloak | кнопка в админке |
| Ключи доступа в карточке пользователя | «есть / нет» | названия и число кодов восстановления в API |
| Список пользователей приложения | из держателей ролей (до 1000 на роль), страницы в памяти | своя модель чтения |
| Журнал «по возможности» | без outbox запись может потеряться | outbox |
| Каталог приложения читается из Keycloak на каждый запрос | без кэша | кэш |
| Демо-эндпоинты `/demo/*` и матрица `check-api.sh` | больше не нужны для проверки прав | убрать |
| Одна тема на проект | оформление приложения — поверх проекта, подробнее не делали | — |
| Проект в кластере создаётся скриптами с машины (port-forward) | — | Job или операция в админке платформы, если проектов станет много |
| Логи, метрики, оповещения, OpenAPI, лимиты на эндпоинтах сервиса | вне этапов | отдельным этапом |
| Postgres и Redis в кластере | внешние, чарт их не ставит | управляемые базы с копиями |
| Тема показывает `+9990000002` для 10 цифр без 7 | сервер понимает как `+79990000002` | мелкая правка скрипта темы |
| Любой номер получает код и становится покупателем | стоимость SMS и «мусорные» пользователи | как в старом сервисе; смягчают лимиты и бюджет |

## Когда пересмотреть решение «Keycloak»

- Перенос существующего сервиса потребует переписать его авторизацию целиком.
- Новая версия Keycloak сломает аутентификаторы так, что починка займёт больше недели.
- Понадобится вход, который Keycloak не умеет и не расширяется SPI без форка.

## Чем отличается от старого (боевого) сервиса

Для тех, кто будет переезжать.

| | Старый | На Keycloak |
|---|---|---|
| Роли | три в коде, у пользователя одна | свои у каждого приложения, сколько угодно; роль = режим |
| Права | карта в коде, новый релиз | в Keycloak, действуют сразу |
| Смена роли | выход из всех сессий | умный рефреш без перелогина |
| Отзыв доступа | токен живёт до 15 минут | сразу |
| Админка | нет своей | админ проекта и админ приложения |
| 2FA, ключи доступа, почта | нет | есть |
| Код на телефон | SMS | звонок-сброс, SMS запасным; лимиты, капча, бюджет |
| Способы входа | одинаковые у всех | человек выключает ненужные, проект задаёт рамки |
| Страницы входа | Razor + htmx, работают без JS | React (Keycloakify), без JS не работают |
| Логин | `+79991110001` | `79991110001`, `phone` — `+7…` |
| `available_roles` | строка | массив |
| Ответы | голые объекты, ProblemDetails | `Envelope` с кодами |
| Cookie | обе на `Path=/`, живут срок refresh | по https `__Host-accessToken` и `__Host-refreshToken`, обе на `Path=/`; локально по http refresh только на `/auth/`; access живёт как токен |
| Сессии при переезде | — | не переносятся: все входят заново |
| `userAgent`, `deviceLabel` сессии, `loginCount` | есть | нет в Keycloak (события — 30 дней) |
