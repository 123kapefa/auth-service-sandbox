# Магазин на сервисе входа

Новый проект «Демо-магазин» (этап 6а.4): «Заказы» — страница магазина и API, «Уведомления» — внутренний сервис.
Подключены к сервису входа так, как подключил бы их чужой проект: пакетами `Platform.*` из фида и ключами сервисов.

```bash
samples/shop/setup.sh                 # проект, права и роли, пользователи, ключи, сборка и запуск
scripts/keycloak/check-shop.sh        # проверка целиком
```

Магазин — http://localhost:5300: покупатель `79995550003`, сотрудник `79995550002` (пароль `Test1234!`), новый
покупатель — «Войти по коду». Письма — http://localhost:8025.
